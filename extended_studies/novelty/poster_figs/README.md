# Poster figures (novelty work)

Generated by `python run.py novelty/make_poster_figures.py` (data figures, from `novelty/results_full/`) and
`pdflatex tikz/F1_workflow.tex`, `pdflatex tikz/F2_architecture.tex` (drawn figures). Each figure is a vector PDF
for the poster plus a PNG preview.

| file | content |
|---|---|
| F1_workflow.pdf | pipeline: true D -> RK4 forward solve -> sensors -> PINN / adjoint -> novelty experiments -> scoring |
| F2_architecture.pdf | PINN (u-net, D-net, loss) and classical adjoint (controls, CN forward, adjoint gradient, L-BFGS-B, alpha path) |
| F3_datasets | the six true D fields and five sensor layouts |
| F4_reconstructions | truth / adjoint / PINN / hybrid on A_smooth, C_inclusion, E_grf |
| F5_unknown_physics | headline: wrong physics vs PINN vs classical estimating the missing walls / source vs bound |
| F6_hybrids | E1 hybrids on 20 datasets, with the 5-seed range of the PINN and hybrid_balance medians |
| F7_density | relL2 vs number of sensors: adjoint and the PINN at 1.5k / 6k / 24k epochs |
| F8_model_error | temperature-dependent D: relL2 vs Arrhenius strength S |
| F9_pinn_practice | median change in the PINN's relL2 from six training interventions |
| F10_time_integrator | backward Euler vs Crank-Nicolson inside the classical adjoint |
| F11_hidden_source | D maps and true vs recovered heater for one hidden-source dataset |

Colours: classical adjoint blue, PINN orange, hybrid / joint classical aqua, true-physics bound grey; D maps use one
single-hue blue ramp on a shared scale per figure.
